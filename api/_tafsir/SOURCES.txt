Nibras AI — Quran tafsir data (Arabic, text unchanged / mətn dəyişdirilməyib)
==============================================================================
Format: every <sura>.js holds the JSON of that sura, brotli-compressed + base64 (api/_tafsir/_unpack.js decodes it; round-trip is verified at build time),
so the data is ~9 MB in the repo (≈98 MB unpacked). The decoded text is identical to the downloaded source.
Generated by: node scripts/build-tafsir.mjs  (raw files downloaded with scripts/download-tafsir.sh on 2026-10-04)

1) muyassar/<sura>.js  — التفسير الميسر (at-Tafsir al-Muyassar)
   Source: QuranEnc.com, translation key `arabic_moyassar`
   https://quranenc.com/en/browse/arabic_moyassar  (API: https://quranenc.com/api/v1/translation/sura/arabic_moyassar/<sura>)
   One entry per ayah; the `translation` field is stored verbatim.

2) saadi/<sura>.js — تيسير الكريم الرحمن في تفسير كلام المنان, عبد الرحمن بن ناصر السعدي
   Source: QuranEnc.com, `arabic_saadi`, public browse pages
   https://quranenc.com/en/browse/arabic_saadi/<sura>
   (the QuranEnc JSON API does not serve this key — it returns an empty body — so the text is taken from the page HTML;
   HTML tags removed, the text of every block is stored as-is, incl. the {…} ayah quotations; blocks are ayah ranges,
   plus the sura introduction `i`). Layout: {i: intro, b: [[fromAyah, toAyah, text], ...]}.

3) ibnkathir/<sura>.js — تفسير القرآن العظيم, الحافظ ابن كثير (Arabic, with tashkeel)
   Source: spa5k/tafsir_api, edition `ar-tafsir-ibn-kathir`
   https://github.com/spa5k/tafsir_api  (code licence: MIT, © 2023 Spark)
   The dataset in that repository is itself derived from Quran.com / Quran.Foundation "QUL" resources
   (https://qul.tarteel.ai/resources/tafsir/22). One entry per ayah, stored verbatim (editorial footnotes in [[…]] included).

QuranEnc.com asks that content is cited with its source and that the text is not altered; both are respected here.
Licensing note: the QuranEnc and QUL/Quran.com terms for redistribution of the tafsir texts were not individually
confirmed beyond attribution; the original works (Ibn Kathir d. 774 H, as-Sa'di d. 1376 H, al-Muyassar) are
published works — if a rights-holder objects, remove the folder and the import in api/_tafsir/loaders.js.
